# KeyMouseTracker 发展路线与优化规划

> 本文档是项目的中期路线图，记录「现状 → 目标 → 阶段拆分 → 验收标准」。已完成的阶段在任务清单中勾选；后续阶段按优先级滚动推进。

## 1. 现状小结（v0.3.2）

- **定位**：本地零依赖 Windows 键鼠使用记录工具，管理员权限运行，全局低层钩子采集，数据仅存本机 `%APPDATA%\KeyMouseTracker\data.bin`（LZSS 无损压缩存储）。
- **架构**：12 个职责单一模块——`data`（模型/持久化/LZSS 压缩）· `hooks`（低层钩子回调脱敏）· `main`（UI 渲染/交互/生命周期）· `timechart`（时间序列图）· `export`（CSV/JSON）· `api`（命名管道 JSON API）· `tray`（系统托盘）· `stats_json`（统计 JSON 构建）· `stats_query`（筛选/明细查询）· `heatmap`（键盘配列+热力色阶）· `uiutil`（纯工具）· `uicolor`（颜色工具）。
- **v0.3.2 变更**：移除 KMT4/v6-v11 向后兼容（~350 行）、LZSS 无损压缩、自适应 UI 刷新频率（16ms↔100ms）、前台事件驱动归因、idleSec 空闲累计、中英双语、API、原子写盘+LZSS 压缩验证+孤儿文件保护、111 项单测、CI。
- **剩余短板**：`main.cpp` 2096 行渲染胶水（E-1 剩余）、数据量线性增长（E-3 待做）。

- **v0.3.2**（当前）：阶段 A（原子写盘+孤儿保护）+ B-2（事件归因）+ C（API）+ D（i18n）+ E-2（测试+CI）+ LZSS 无损压缩 + 自适应刷新 + 移除向后兼容

- 后续：E-3/E-4/E-5 按价值滚动。

## 4. 关键约定

- **钩子回调硬约束**：`WH_KEYBOARD_LL/WH_MOUSE_LL` 回调有系统超时（默认约 300ms），回调内只允许 O(1) 工作；任何 map 分配/IO/重计算一律移出回调（A-2 后由计时器排空兜底）。
- **跨线程读数据**：`app()` 数据仅在主线程读写；后台线程（管道服务）不得直接访问，统一走「主线程快照」模式。
- **隐私红线**：新增能力不得联网、不得记录按键内容；API 仅监听本机命名管道，不监听任何网络端口。
